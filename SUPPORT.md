# Support

## Help with an application, a license or a purchase

Visit [arctisoft-studio.com/support](https://arctisoft-studio.com/support/) or write to **support@arctisoft-studio.com**.

Tell us the application, its version and what happened. For an order, include your order reference. Never send a password, a sign-in code or full payment-card details.

Help & Support in Studio Hub can attach diagnostic details to a request, which usually shortens the conversation.

## Issues in the release repositories

The release repositories publish documentation, release notes and installers. Use an issue there to report a reproducible defect in a published release. Questions about accounts, licenses, purchases and personal data are handled by email, not in public issues.

## Security

Please follow the [security policy](SECURITY.md) and do not report vulnerabilities in public.
