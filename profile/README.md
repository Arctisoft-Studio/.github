**Arctisoft Studio** is an Austrian software studio. We design and build native desktop applications for people who work with audio and media. Each application concentrates on one discipline and is taken as far as that work requires. Every released application has a free edition; paid editions are bought once and licensed perpetually.

### The Collection

| Application | Discipline | Edition |
| --- | --- | --- |
| **WaveShaper** | Audio Processing Studio. Equalisation, dynamics, effects, mastering and export in one signal chain. | Free · Premium |
| **Sonaris** | Audio Quality Analyzer. Loudness, true peak, dynamics, spectrum and stereo measurement with delivery checks and reports. | Free |
| **MetaEdit Plus** | Advanced Tag Editor. Batch metadata editing, rules, artwork collections, native chapters and indexed libraries. | Free |
| **Medio** | Universal Downloader. Source and stream selection, queues and hardware-accelerated conversion. | Free · Premium |
| **Studio Hub** | Installs, updates and launches every application, and manages your account, licenses and purchases. | Free |
| **MixForge** | Digital Audio Workstation for recording, arranging and mixing. | In development |

### Releases

Installers and release notes are published in each application's release repository. The recommended way to install and update the collection is **Studio Hub**, which reads those releases for you.
