Arctisoft Studio develops desktop software for work with sound and media: processing and mastering, measurement and delivery control, metadata and library care, and media acquisition. Each application is a complete workstation for its discipline. They share one account, one license system and one design language, and Studio Hub installs, updates and licenses the whole collection from one place.

## Editions

Every application has a free Basic edition. Premium is a one-time purchase for one person, covering the licensed major version and all of its updates, with a 14-day trial available once per account and computer. Current offers are listed under [editions and pricing](https://arctisoft-studio.com/pricing/); the [License Agreement](https://arctisoft-studio.com/legal/license/) states the terms.

## Downloads and support

Each application's repository holds its documentation, release notes and installers. Installers are verified against the SHA-256 checksum GitHub publishes for every release file, and Studio Hub keeps the collection up to date.

For help with an application, an account, a license or an order, visit [Arctisoft Support](https://arctisoft-studio.com/support/) or write to [support@arctisoft-studio.com](mailto:support@arctisoft-studio.com). Report a reproducible defect in a published release through that application's issues. Security reports are handled privately, as described in the [security policy](https://github.com/Arctisoft-Studio/.github/blob/main/SECURITY.md).
