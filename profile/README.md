Arctisoft Studio is an Austrian software studio building desktop applications for audio processing, measurement, metadata and media acquisition. Each product serves its own discipline; Studio Hub brings their installation, updates, accounts and licenses together.

## The collection

| Application | Discipline | Editions |
| --- | --- | --- |
| [WaveShaper](https://github.com/Arctisoft-Studio/WaveShaper-Audio-Processing-Studio) | Audio processing, effects, mastering and export | Basic · Premium |
| [Sonaris](https://github.com/Arctisoft-Studio/Sonaris-Audio-Quality-Analyzer) | Audio measurement, comparison and delivery checks | Basic · Premium |
| [MetaEdit](https://github.com/Arctisoft-Studio/MetaEdit-Advanced-Tag-Editor) | Metadata, artwork and library organisation | Basic · Premium |
| [Medio](https://github.com/Arctisoft-Studio/Medio-Universal-Downloader) | Media downloading and conversion | Basic · Premium |
| [Studio Hub](https://github.com/Arctisoft-Studio/Arctisoft-Studio-Hub) | Application, account and license management | Free |
| [MixForge](https://arctisoft-studio.com/software/mixforge/) | Recording, arranging and mixing | In development |

The product websites present each application's capabilities and gallery. See [current editions and pricing](https://arctisoft-studio.com/pricing/) for the available offers. Premium licenses cover the major version purchased and its updates; the [License Agreement](https://arctisoft-studio.com/legal/license/) states the terms.

## Releases and support

Public release repositories contain product documentation, release notes and published installers. Draft releases remain unpublished; a repository without a published release has no public installer available there. Application source code and engineering materials remain private.

For product, account, license and purchase assistance, visit [Arctisoft Support](https://arctisoft-studio.com/support/) or email [support@arctisoft-studio.com](mailto:support@arctisoft-studio.com). Send security reports privately to the same address; do not post vulnerabilities, license keys or personal account details in public issues.
